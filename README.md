# 10月30日 · 视频记录

一个适合手机和电脑观看的静态视频页面，通过 GitHub Pages 发布。

## 文件

- `index.html`：网页、播放器和样式。
- `video.mp4`：1080p、30 fps、H.264/AAC 网页播放版本。
- `poster.jpg`：从视频中截取的封面。
- `.nojekyll`：让 GitHub Pages 直接提供静态文件。

## 维护

在仓库的 Settings → Pages 中，选择 Deploy from a branch、`main`、`/(root)`。

修改网页标题可编辑 `index.html`。更新视频时替换同名 `video.mp4`，同时更新封面和时长文字；保留账号名、仓库名与页面路径，以便已分享的二维码继续使用相同网址。

此仓库公开提供网页和视频。视频没有预设的链接到期时间；可用性取决于 GitHub Pages 服务、账号和仓库持续保留。仓库公开不代表视频版权转让。
